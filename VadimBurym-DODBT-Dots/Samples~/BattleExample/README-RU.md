# Пример использования DODBT для DOTS

Пример интеграции дерева поведения в Unity ECS. В одной сцене сражаются 5 000 пехотинцев и 5 000 орков: находят противников, перемещаются и атакуют. На этом показаны общий blob дерева, состояние каждого агента, выполнение через Burst и Jobs, а также отладка в редакторе.

**Этот пример не является рекомендацией по архитектуре проекта.** Он помогает быстро разобраться в работе плагина и его подключении. Боевые системы и организация сцены упрощены для демонстрации; интеграцию в свою игру стоит строить с учетом ее требований.

## Требования

- Unity **6000.3.10f1**.
- DODBT-Dots.
- Entities **1.5.0** и Entities Graphics **1.5.0**.
- Universal RP **17.3.0** и Input System **1.18.0**.

Это версии, на которых проверен пример. Entities, Burst, Collections и Mathematics устанавливаются вместе с плагином. Entities Graphics, URP и Input System установите через Package Manager. Для сцены нужен проект с настроенным URP.

## Запуск

Пример поставляется в скрытой папке `Samples~`. После установки пакета импортируйте его в проект:

1. В Package Manager выберите **DODBT-Dots > Samples > Battle Example > Import**.
2. Откройте [BattleExample.unity](BattleExample.unity) в импортированной папке.
3. Нажмите **Play**.

Количество бойцов, расстановка и случайный seed задаются в компоненте `Battle Example`. Пример использует отдельный ECS World и не меняет настройки проекта. В одном проекте должна быть одна импортированная копия примера. Первый запуск может задержаться на компиляции Burst. Модели, анимации, деревья и параметры боя находятся в `Content/Units/Footman.asset` и `Orc.asset`. По умолчанию обе армии используют одно дерево.

## Управление и отладка

- **WASD**, стрелки или края экрана: перемещение камеры.
- **Колесо мыши**: приближение и отдаление.
- **Observe** над выбранным юнитом в Scene View: открыть его дерево в режиме отладки.

Список агентов доступен через **Tools > VadimBurym > DODBT-Dots > BT Debugger**. Подключение отладки в примере уже выполнено.

Панель Frame/FPS показывает среднее время всего кадра и FPS, обновляясь четыре раза в секунду. Плашка **Entities** считает оставшихся агентов с `AiBrain`, исключая сущности рендеринга, трупы и служебные сущности. Запрос считает сущности в чанках без завершения Jobs и копирования массива. Для замера без HUD отключите `BattleHud`.

## Устройство примера

`BattleSession` создает собственный ECS World через `BattleWorld` и устанавливает системы боя. Сессии имеют независимые World, материалы и VAT-буферы. При остановке завершаются запущенные Jobs, освобождается World, затем общие данные деревьев, навигации и анимации. Одинаковые деревья используют один blob; изменяемое состояние хранится отдельно на каждом агенте.

Дерево решает, нужно ли обнаружить противника, приблизиться и атаковать либо продолжать движение или ожидать. Каждый агент вызывает его раз в 0.2 секунды, со сдвигом между агентами. В листьях используются числовые `int` ID 0–7. `DistanceToEnemyThresholdLeaf.Equal` сравнивает квадраты расстояний с абсолютным допуском меньше `1e-6`; в текущем боевом дереве этот лист не используется.

VAT-шейдер использует одинаковые анимированные вершины для изображения, выбора объекта и контура выделения. `RenderBounds` охватывают область кодирования VAT для всех клипов и смешиваний, с запасом 0.01 с каждой стороны. Границы назначаются при создании юнитов, а не пересчитываются каждый кадр. Масштаб импорта, порядок вершин и текстуры анимации не меняются.
