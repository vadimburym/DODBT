# DODBT 0.3.1

Release date: 2026-10-12.

This patch fixes nested selector traversal, parallel abort bookkeeping, and editor debug state. The standalone package and the plugin inside `example-project` contain the same version. DODBT has no Odin dependency; unrelated example-project dependencies remain separate.

## Installation

```text
https://github.com/vadimburym/DODBT.git?path=/source#v0.3.1
```

The release provides a UPM tarball, a plugin source ZIP, a validation ZIP, and `SHA256SUMS.txt`.

## Fixed bugs

- **Nested MemorySelector traversal:** a nested selector could overwrite the shared shuffle buffer of its parent, causing siblings to be skipped or visited repeatedly in a fresh traversal. Random selectors now have independent buffer segments allocated once during tree construction. Ordered selectors execute directly in left-to-right order.
- **Parallel abort bookkeeping:** with `CacheChildStatus` disabled, a completed child could retain an internal Running marker. A later abort could consequently reset an already failed MemorySequence that was supposed to retain its position. Completed children now clear that marker.
- **Debug state after aborts:** a leaf that returned Running earlier in a tick could still appear active after another branch caused its abort. Active-leaf lists now reflect the final entered state and retain traversal order. Explicit abort and state initialization clear stale debug state.
- **Cached Parallel results:** completed children skipped on later ticks now retain their cached Success/Failure colors in Debug Mode.

## Compatibility and memory

The type picker also has a refreshed layout: white leaf icons, emphasized class names, gray namespace labels, larger row spacing, a current-type check mark, and keyboard hints. Search still supports class names and namespaces; full names are available in tooltips. Assembly names remain hidden. Selection supports mouse, arrow keys, Page Up/Down, Enter, and Escape.

Existing graphs and compiled assets require no format migration. Serialized field names, script GUIDs, public runtime API, leaf callbacks, and reset settings are retained.

MemorySelector still restarts its search from the beginning after its remembered child fails, including retrying that child. This existing behavior is different from the unintended duplicate visits fixed in this release.

Shuffle storage grows with the sum of child counts of random selectors, instead of the maximum child count of a single node. It is shared by agents using the runtime tree and allocated during `Construct`, not per agent or per tick. Additional debug bookkeeping is editor-only. Sequential use of a shared tree by multiple agents is covered; this release does not add concurrent or reentrant execution support.
